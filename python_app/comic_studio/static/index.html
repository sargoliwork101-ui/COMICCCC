مدل‌های OCR و آزمایش

Tesseract در افزونه اصلی می‌ماند. این مدل‌ها فقط برای برنامهٔ مستقل Python هستند و بدون کلیک شما دانلود نمی‌شوند.

آزمایش روی نخستین تصویر انتخاب‌شده انجام می‌شود و پروژه را تغییر نمی‌دهد.
