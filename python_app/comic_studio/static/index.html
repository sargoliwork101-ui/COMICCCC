OCR آفلاین

بعد از OCR، متن خوانده‌شده در گزارش و روی تصویر می‌آید تا پیش از ترجمه بررسی و ویرایش شود.

ترجمهٔ متن‌ها

آماده

در سرویس رایگان، متن OCR همهٔ کادرهای فعال انتخاب‌شده با جداکنندهٔ ␞ جمع می‌شود و اگر طولش حداکثر ۵۰۰ نویسه باشد، فقط در یک query می‌رود و پاسخ دقیقاً بین همان کادرها تقسیم می‌شود. اگر متن جمعی بیشتر از ۵۰۰ نویسه باشد، کادرها برای جلوگیری از خطای سقف جدا می‌روند و هر query در آخرین ته‌جمله قبل از سقف بسته می‌شود. با API هوش مصنوعی، همهٔ متن‌ها در یک درخواست جمعی با ␞ می‌روند. جداکننده در متن نهایی دیده نمی‌شود و نتیجه فقط بعد از موفقیت همهٔ بخش‌ها ذخیره می‌شود.

مدل‌های OCR و آزمایش

هیچ مدلی بدون کلیک شما دانلود نمی‌شود. بخش اول مستقیماً با ویرایشگر کار می‌کند. بخش دوم فقط لینک رسمی دانلود/راه‌اندازی دارد؛ این مدل‌های VLM به محیط جدا و خروجی سازگار با کادرهای کمیک نیاز دارند و فعلاً در فهرست اجرای OCR ظاهر نمی‌شوند. راهنمای نصب برنامه از همین شاخهٔ GitHub. لینک کارت‌های بخش دوم برای نصب جداگانه و طبق README همان پروژه است، نه نصب خودکار داخل این برنامه.

فقط اگر نصب در ویندوز خطای دسترسی داد، برنامه را ببندید و فایل start_windows_admin.bat را اجرا کنید. پس از تأیید پیام UAC، نصب OCR با دسترسی مدیر انجام می‌شود؛ دانلود مدل‌های اختیاری همچنان فقط با کلیک شماست.

آماده‌سازی فقط همین زبان را نصب/دانلود می‌کند. آزمایش روی نخستین تصویر انتخاب‌شده انجام می‌شود و پروژه را تغییر نمی‌دهد.

تنظیمات خروجی

    
    
    

    

    
در PDF و ZIP، انتخاب فارسی/انگلیسیِ هر کادر همان‌طور اعمال می‌شود؛ بنابراین یک صفحه می‌تواند بعضی متن‌ها را فارسی و بعضی را انگلیسی داشته باشد. انتخاب کلی پیش‌فرض متن‌های بدون انتخاب جداگانه است و «بدون متن» تصویر اصلی را خروجی می‌دهد. فقط تصاویر انتخاب‌شده خروجی می‌گیرند و اعضای هر گروه در یک صفحهٔ عمودی PDF می‌مانند.

    

    

  

  
    
ویرایش متن

    
100٪
برای هر متن می‌توانید جداگانه «فارسی / ترجمه» یا «انگلیسی / OCR» را انتخاب کنید: دکمهٔ فا/EN روی همان کادر یا انتخابگر «نمایش همین متن» در کارتش این کار را می‌کند. انتخاب کلی بالای صفحه پیش‌فرض متن‌های بدون انتخاب جداگانه است و «بدون متن» همه را پنهان می‌کند. با 👁 روی هر کادر یا تیک «نمایش متن»، فقط همان خط پنهان یا نمایان می‌شود؛ متن و ترجمه‌اش حذف نمی‌شود. روی متن داخل تصویر یا کارت سمت راست تایپ کنید. چرخ ماوس زوم می‌کند و کشیدن فضای خالی تصویر را جابه‌جا می‌کند؛ برای جابه‌جایی کادر، ⠿ یا لبهٔ آن را بکشید. Ctrl+S ذخیره می‌کند.
متنی انتخاب نشدهCtrl/⌘ + کلیک برای چند انتخاب؛ کشیدن ⠿ همهٔ انتخاب‌شده‌ها را جابه‌جا می‌کند.
