# Comic OCR Studio 3.00

برنامهٔ مستقل Python برای کار روی خروجی افزونه: **PDF یا تصویر ورودی → OCR → ترجمه/AI → ویرایش → PDF، ZIP تصویر یا TXT**.

این برنامه به افزونه وصل نمی‌شود و هیچ تصویری از وب‌سایت جمع‌آوری نمی‌کند. افزونه فقط جمع‌آورندهٔ تصاویر سایت باقی می‌ماند.

## اجرا

به Python 3.11 یا جدیدتر نیاز است. در همین پوشه:

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[ocr]'
.venv/bin/python run.py
```

در ویندوز، به‌جای `.venv/bin/...` از `.venv\\Scripts\\...` استفاده کنید. پس از اجرا، صفحهٔ برنامه به‌صورت خودکار در مرورگر باز می‌شود؛ نشانی پیش‌فرض `http://127.0.0.1:8765` است.

اگر نمی‌خواهید مرورگر خودکار باز شود:

```bash
.venv/bin/python run.py --no-browser
```

اجرای بدون بستهٔ OCR هم ممکن است، اما برای استفاده از PP-OCR باید extra به نام `ocr` نصب شود. نصب بسته‌ها و آماده‌سازی مدل‌ها باید با انتخاب شما انجام شود.

## امکانات

- ورود چند فایل تصویری یا PDF؛ صفحات PDF به تصویرهای قابل ویرایش تبدیل می‌شوند.
- پروژه‌های ذخیره‌شونده روی کامپیوتر، انتخاب همه/هیچ/معکوس، ترتیب دستی و کشیدن کارت‌ها، گروه‌بندی، کپی و حذف.
- OCR محلی با PP-OCRv6 Small؛ PP-OCRv5 Multilingual و EasyOCR به‌عنوان گزینهٔ جداگانه.
- آزمایش موتور روی نخستین تصویر انتخاب‌شده بدون تغییر دادن پروژه.
- ترجمهٔ رایگان با مسیر جایگزین، یا AI سازگار با OpenAI با نشانی و مدل قابل تنظیم.
- ویرایش متن OCR و ترجمه، قالب‌بندی غنی، راست‌به‌چپ/چپ‌به‌راست، تراز، اندازه، رنگ، پاک‌کردن متن اصلی و انتخاب پس‌زمینه.
- جابه‌جایی و تغییر اندازهٔ کادر ترجمه با هشت دستگیره، برش تصویر و پیش‌نمایش نهایی.
- خروجی PDF معمولی، قاب‌های هم‌اندازه، دو تصویر در صفحه و حالت seamless؛ خروجی ZIP با فرمت اصلی/PNG/JPEG و خروجی متنی با تورفتگی.

## مدل‌ها و حریم خصوصی

- OCR روی همین کامپیوتر انجام می‌شود. در حالت عادی، اجرای OCR حق دانلود مدل ندارد.
- PP-OCRv6 Small در بستهٔ آزمایش‌شدهٔ RapidOCR 3.10.0 همراه مدل‌های لازم است و روی CPU آزمایش شده است.
- PP-OCRv5 و EasyOCR فقط از دکمهٔ «آماده‌سازی / دانلود مدل» یا نصب آگاهانهٔ بستهٔ مربوط آماده می‌شوند. برای PP-OCRv5 مدل‌ها در پوشهٔ دادهٔ برنامه نگهداری می‌شوند.
- دقت روی صفحات واقعی کمیک برای همهٔ زبان‌ها هنوز اندازه‌گیری نشده است؛ دکمهٔ آزمایش برای مقایسهٔ واقعی روی تصویر خودتان است.
- ترجمهٔ رایگان و AI آنلاین به اینترنت نیاز دارند و فقط متن OCR را ارسال می‌کنند، نه تصویر را. برای AI محلی می‌توانید نشانی یک سرویس محلی سازگار با OpenAI وارد کنید.
- کلید API فقط در فایل تنظیمات محلی برنامه ذخیره می‌شود و در پاسخ‌های API یا رابط نمایش داده نمی‌شود.

## محل داده‌ها

به‌صورت پیش‌فرض پروژه‌ها و مدل‌های دانلودشده در `~/.comic-ocr-studio/` هستند، نه در پوشهٔ افزونه. برای تغییر محل:

```bash
COMIC_STUDIO_DATA=/path/to/data .venv/bin/python run.py
```

## آزمایش‌ها

```bash
.venv/bin/pip install -e '.[ocr,dev]'
.venv/bin/pytest
# آزمایش عمدی مدل واقعی، بدون دانلود خودکار:
COMIC_STUDIO_REAL_OCR=1 .venv/bin/pytest -m real_ocr
```

از ریشهٔ مخزن نیز `npm test` تست‌های افزونهٔ 2.55 را بدون تغییر در کد آن اجرا می‌کند.

## اجرای API بدون رابط پیش‌فرض

برنامه با FastAPI ساخته شده است؛ رابط اصلی همان فایل‌های محلی `comic_studio/static/` است و تمام درخواست‌های مرورگر نسبی هستند. برای اجرای مستقیم سرور:

```bash
.venv/bin/uvicorn comic_studio.main:app --host 127.0.0.1 --port 8765
```
