تنظیمات API هوش مصنوعی

سرویس، مدل و کلیدهایی را که می‌خواهید افزونه برای ترجمه استفاده کند اینجا تنظیم کنید.

موتور ترجمهٔ صفحه

این انتخاب برای ترجمهٔ کپی صفحهٔ وب است. سرویس و مدل هوش مصنوعی را جداگانه انتخاب کنید.

می‌توانید چند کلید ثبت کنید؛ افزونه آن‌ها را به ترتیب امتحان می‌کند. «تست» یک جملهٔ ثابت را برای سنجش تولید ترجمه می‌فرستد، نه متن صفحه یا کمیک.

کلیدها در فضای محلی افزونه در همین مرورگر ذخیره می‌شوند. هنگام ترجمه، متن صفحه برای سرویس انتخاب‌شده فرستاده می‌شود؛ HTML کامل، نشانی صفحه و کلید API در متن ترجمه قرار نمی‌گیرند. از فرستادن اطلاعات حساس خودداری کنید.
