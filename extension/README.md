# HASAYA — افزونهٔ ۳.۵ (3.5.0)

## دریافت تصویر با وضوح اصلی

افزونه بیشترین وضوح معرفی‌شده در منابع خود صفحه را انتخاب می‌کند. چهار ایراد انتخاب منبع اصلاح شده است:

1. `data-original` قبلاً بدون مقایسه فوراً انتخاب می‌شد، حتی اگر نشانی آن محدودیت `w=240` داشت و صفحه نسخهٔ `2000w` معرفی کرده بود. اکنون اندازهٔ شناخته‌شده با سایر گزینه‌ها مقایسه می‌شود؛ تمام صفت‌های original/full بررسی می‌شوند، نه فقط اولین مورد.
2. امتیاز `2x` از عرض کوچک CSS محاسبه می‌شد و گاهی از تصویر `1x` بارگذاری‌شده پایین‌تر قرار می‌گرفت. اکنون عرض ذاتی اصلاح‌شده از نظر تراکم نیز لحاظ می‌شود.
3. جداکردن سادهٔ `srcset` با ویرگول، نشانی‌هایی مانند `/upload/w_2400,q_auto/book.jpg` را خراب می‌کرد. اکنون توکن نشانی از توصیفگر جدا می‌شود و ویرگول داخل نشانی حفظ می‌شود.
4. انتخابگر دستی که مستقیماً به `source` اشاره می‌کرد فقط اولین نامزد را برمی‌داشت؛ اکنون بزرگ‌ترین نامزد انتخاب می‌شود.

پارامترهای امضا یا نام فایل به‌صورت حدسی حذف/بازنویسی نمی‌شوند. نشانی original که هیچ اطلاعات اندازه‌ای ندارد هنوز بر اساس نام صفت سایت معتبر فرض می‌شود؛ این تضمین ابعاد واقعی آن نیست. بدون نمونهٔ سایت کاربر نمی‌توان تضمین کرد هر CDN، محدودیت دسترسی یا روش اختصاصی lazy loading پوشش داده شده است.

### محدودیت مهم «کیفیت اصلی»

- اگر سایت فقط نسخهٔ کوچک یا فشرده را منتشر کند، افزونه نمی‌تواند پیکسل‌های حذف‌شده را بازیابی کند.
- یکسان‌بودن ابعاد لزوماً به معنی یکسان‌بودن فشرده‌سازی نیست؛ کیفیت پاسخ را سرور سایت نیز تعیین می‌کند.
- کوچک‌سازی ۲۴۰پیکسلی پیش‌نمایش، مربوط به کارت نمایش است، نه فایل خروجی.
- برای حفظ بایت‌های دریافتی در تصویر بدون ویرایش/کراپ، «تصاویر جدا → فرمت اصلی» را انتخاب کنید. فایل اصلی در این مسیر دوباره به JPEG تبدیل نمی‌شود.
- تبدیل به JPEG با کیفیت ۱۰۰٪ همچنان می‌تواند با افت باشد. ساخت PDF، برش، تبدیل و جای‌گذاری ترجمه ممکن است بازکدگذاری داشته باشند؛ این مسیرها ادعای برابری بایتی با فایل سایت ندارند.

## OCR دقیقاً کجا انجام می‌شود؟

**داخل Chrome، با Tesseract.js / WebAssembly و روی پردازنده و حافظهٔ همین دستگاه.**

- worker، هستهٔ WASM و مدل زبان از `extension/vendor/ocr/` بستهٔ افزونه خوانده می‌شوند.
- مدل‌های انگلیسی، کره‌ای، ژاپنی و چینی ساده‌شده در بسته موجودند. این موتور، PP-OCR برنامهٔ Python نیست و برای اجرا به Studio نیاز ندارد.
- خود تصویر برای OCR به سایت بیرونی آپلود نمی‌شود. دریافت اولیهٔ تصویر از سایت مبدأ، ارتباط جداگانه‌ای است و همچنان لازم است.
- **ترجمه محلی نیست:** متن استخراج‌شده برای Google Translate / MyMemory یا سرویس AI انتخابی (Gemini، OpenAI، OpenRouter، AvalAI) ارسال می‌شود. سرویس و تنظیمات فعال را پیش از ترجمه بررسی کنید؛ متن حساس نفرستید.
- متن وب‌سایت در «ترجمهٔ همین صفحه» از DOM خوانده می‌شود؛ این قابلیت اصولاً OCR تصویر نیست.
- تبدیل PDF به تصویر با PDF.js هم محلی است.

## ظاهر و دسته‌بندی

صفحهٔ اصلی، پیش‌نمایش، تنظیمات AI و واردکردن PDF، رنگ‌ها و فونت یکسان با Studio دارند. فایل Vazirmatn افزونه و Studio از نظر بایت یکسان است؛ فونت از اینترنت دریافت نمی‌شود. نوار ترجمهٔ کپی صفحه هم فونت محلی اختصاصی خودش را دارد و فونت بدنهٔ سایت تغییر نمی‌کند.

- صفحهٔ اصلی: «جمع‌آوری و تنظیمات تصویر» و «ابزارها و خروجی».
- پیش‌نمایش: «ورود فایل»، «انتخاب و حذف»، «گروه‌بندی صفحات»؛ منوی بالا «پروژه و پروفایل» و «خواندن متن و ترجمه».
- آیکون‌های خطی یکدست با عنوان‌های فارسی حفظ شده‌اند؛ آیکون تزئینی جای برچسب قابل‌فهم را نگرفته است.
- دکمهٔ روشن/تیره در سربرگ چهار صفحه، تنظیم را محلی و مشترک میان صفحه‌های افزونه ذخیره می‌کند. این تنظیم مستقل از ترجیح برنامهٔ Python است؛ نوار تزریقی روی کپی سایت فعلاً سبک تیره دارد.
- حالت فوکوس کیبورد و کاهش حرکت/شفافیت سیستم رعایت می‌شود. تنها فونت بسته‌بندی‌شده برای نمایش نوار روی سایت در منابع قابل‌دسترسی manifest معرفی شده؛ مدل‌ها یا کلیدها عمومی نشده‌اند.

## نصب به‌روزرسانی

پوشهٔ `extension` جدید را جایگزین کنید؛ در `chrome://extensions` روی Reload بزنید و تب‌های قدیمی پیش‌نمایش را دوباره باز کنید. برای بررسی دوبارهٔ کیفیت، جمع‌آوری تازه انجام دهید؛ فهرست ذخیره‌شدهٔ قدیمی خودکار نشانی‌های جدید پیدا نمی‌کند.

## تست‌ها و محدودهٔ اعتبار

از ریشهٔ مخزن:

```sh
npm ci
npm test
npm run test:extension-browser
npm run test:studio -- --browser
```

- سه تست جدید انتخاب منبع روی کد قبلی شکست خوردند و پس از اصلاح گذشتند؛ مسیر انتخابگر `source` نیز تست مستقل دارد.
- آزمون‌های ظاهر، ذخیره/همگام‌سازی تم، دسته‌بندی، منابع فونت و مسیرهای محلی worker/model در `test-extension-studio-ui.cjs` هستند.
- آزمون Chromium روی Linux، چهار صفحه را با CSS/فونت واقعی و تم روشن/تیره بدون سرریز افقی می‌سنجد و Tesseract واقعی عبارت `HELLO LOCAL OCR` را می‌خواند؛ مسیرهای worker/core/model از یک سرور آزمایشی محلی معادل فایل‌های بسته بارگذاری می‌شوند. در بخش نمایش، اسکریپت‌های عملیاتی حذف می‌شوند تا پروژه یا دانلود واقعی ایجاد نشود؛ تست رفتار کنترل‌ها همچنان در `npm test` است.
- این آزمایش، نصب واقعی unpacked extension روی همهٔ نسخه‌های Chrome یا سایت کاربر نیست. برای نمونهٔ سایتی که هنوز وضوح نامناسب می‌دهد، نشانی صفحه و تصویر موردنظر لازم است.
- مجموعهٔ عمومی مرورگر Studio همچنان timeout شناخته‌شدهٔ ویرایشگر در خط ۴۱۳ دارد؛ با افزودن این تست‌ها پنهان نشده است.
