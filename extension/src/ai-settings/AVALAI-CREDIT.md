# نسخهٔ ۳.۳۴ — استعلام ساده و درخواست/پاسخ خام

نمای سادهٔ AvalAI: دکمهٔ «استعلام اعتبار» موجودی حساب را می‌گیرد، نه لزوماً ماندهٔ همان کلید. روش‌های مصرف ۲۴ساعته، فهرست تراکنش‌ها، هزینهٔ درخواست‌های مشخص و اجرای همه داخل «بررسی پیشرفته» هستند. برای lookup شناسهٔ درخواست UUID لازم است. درخواست ارسالی (روش، آدرس، هدرهای تعیین‌شده توسط افزونه و بدنه) و پاسخ خام دریافتی با وضعیت HTTP نمایش داده می‌شوند؛ مقدار کلید محرمانه مخفی است. اگر پاسخ نرسد، نبود پاسخ/HTTP صریحاً اعلام می‌شود. سایر اطلاعات حساب ممکن است حساس باشند. با ویرایش ورودی‌ها نتایج پاک می‌شوند؛ نتیجه ذخیره نمی‌شود. این ابزار مانده یا انقضای اختصاصی کلید را محاسبه نمی‌کند.

# نسخهٔ ۳.۳۳ — استعلام‌های یکجا

استعلام همهٔ روش‌های مستند: اعتبار حساب، خلاصهٔ ۲۴ساعته، فهرست تراکنش‌ها با بازهٔ ۱ تا ۷۲۰ ساعت و شمارهٔ صفحه (۱۰۰ رکورد)، و lookup با ۱ تا ۱۰۰ شناسهٔ درخواست UUID. بدون شناسهٔ درخواست، lookup اجرا نمی‌شود. برای فهرست می‌توانید شناسهٔ عددی کلید را فیلتر کنید؛ بدون آن ممکن است اطلاعات کل حساب برگردد. هر پاسخ خام با آدرس روش و HTTP جدا نمایش داده می‌شود؛ کلید واردشده مخفی است ولی سایر داده‌ها حساس‌اند. تغییر ورودی نتایج را پاک می‌کند. این روش‌ها مانده یا انقضای اختصاصی کلید را تضمین نمی‌کنند و هیچ صفحه‌بندی خودکاری انجام نمی‌شود.

# استعلام آزمایشی AvalAI — افزونه ۳.۲۹

۱. تنظیمات API هوش مصنوعی را از پنل اصلی افزونه باز کنید.
۲. موتور ترجمهٔ صفحه را روی هوش مصنوعی و سرویس را روی AvalAI بگذارید تا بخش کلیدها دیده شود.
۳. کلید آزمایشی را در ردیف خودش وارد کنید و «استعلام اعتبار AvalAI» را بزنید. ذخیرهٔ تنظیمات برای خود استعلام لازم نیست؛ ذخیرهٔ معمول تنظیمات همچنان کلید را محلی نگه می‌دارد.
۴. برای به‌روزرسانی همان دکمه را دوباره بزنید. دریافت فقط با کلیک شماست و ترجمه‌ای انجام نمی‌شود.

اطلاعات از `GET https://api.avalai.ir/user/v1/credit` با همان کلید ردیف دریافت می‌شود. نمایش شامل مانده و سقف **حسابِ برگشتی سرویس**، مانده و پایان بسته‌ها/اعتبارهای تشویقی (اگر موجود باشد) و زمان آخرین دریافت موفق است. این زمان در خود افزونه ساخته می‌شود؛ نتیجه ذخیره نمی‌شود. تاریخ انقضای اختصاصی کلید از این پاسخ قابل تعیین نیست.

این ابزار برای مقایسهٔ پاسخ چند کلید است؛ **اعتبار نشان‌داده‌شده را بودجهٔ قطعی همان کلید فرض نکنید**. ممکن است کلید محدود هم اطلاعات حساب اصلی را ببیند. برای آزمایش کلیدهای کم‌خطر با سقف‌های متفاوت استفاده کنید. کلید اصلی را در چت یا تصویر به اشتراک نگذارید. هنوز لایسنس، شارژ یا محدودکردن مصرف اضافه نشده است.

درخواست ۱۵ ثانیه مهلت دارد. خطای شبکه/مجوز، دادهٔ نامعتبر و محدودیت تعداد استعلام نمایش داده می‌شود؛ شکست درخواست به معنی صفرشدن موجودی نیست. با ویرایش کلید نتیجه پاک و درخواست قبلی لغو می‌شود. نتیجهٔ قدیمی برای کلید جدید نمایش داده نمی‌شود. از نسخهٔ ۳.۳۲، بدنهٔ پاسخ همراه کد HTTP در همان کادر نشان داده می‌شود؛ تکرار کلید واردشده مخفی می‌شود، ولی سایر اطلاعات حساب ممکن است حساس باشند. پاسخ با textContent نمایش داده می‌شود و HTML اجرا نمی‌شود. حداکثر ۲۰۰ هزار نویسه با اعلام صریح برش نمایش داده می‌شود. از نسخهٔ ۳.۳۴ اطلاعات درخواست و نام هدر Authorization با مقدار مخفی‌شده نمایش داده می‌شوند.

مرجع قرارداد پاسخ: https://docs.avalai.ir/en/api-reference/user

## آزمایش مصرف کلیدها — نسخهٔ ۳.۳۱

کنار استعلام موجودی، «آزمایش مصرف کلیدها (۲۴ ساعت)» را بزنید. درخواست فقط خواندنی به مسیر رسمی `GET /user/v1/transactions/summary?group_by=api_key&hours_ago=24` است؛ در صورت ورود شناسهٔ عددی، `api_key_id` هم اضافه می‌شود. شناسهٔ کلید با خود کلید API فرق دارد؛ آن را از گزارش/پنل سرویس بردارید، نه از روی حدس.

گزارش بازهٔ برگشتی، تعداد درخواست و هزینهٔ کل پاسخ به UNIT، سپس شناسه/پسوند/درخواست/توکن گروه‌ها را نشان می‌دهد. هزینهٔ کل پاسخ را مصرف یک کلید فرض نکنید. تطبیق چهار نویسهٔ آخر فقط احتمالی است؛ چند کلید ممکن است پسوند یکسان داشته باشند. اگر شناسهٔ گروه با فیلتر فرق کند، هشدار نمایش داده می‌شود. برای مقایسه از دو کلید با مصرف متفاوت استفاده کنید و بررسی کنید فیلتر واقعاً عمل می‌کند. بدون فیلتر ممکن است کلیدهای دیگر حساب هم دیده شوند؛ این برای فروش مستقیم کلید نکتهٔ امنیتی مهمی است.

طبق مستندات بازهٔ summary حداکثر ۲۴ ساعت و کش سرویس ۲ دقیقه است. گزارش خالی به معنی مصرف کل عمر صفر نیست. این آزمایش بودجه، انقضا یا ماندهٔ دقیق را محاسبه نمی‌کند و چیزی ذخیره نمی‌کند. هنوز لایسنس و سیستم فروش ساخته نشده‌اند. با تغییر کلید یا شناسه، نتیجه پاک و درخواست قبلی لغو می‌شود؛ خطا یا گزارش ناشناخته هیچ ماندهٔ تخمینی تولید نمی‌کند.
