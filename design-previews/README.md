# پیشنهادهای مستقل رابط popup — نسخهٔ نمونه 1

فایل `index.html` را مستقیماً در مرورگر باز کنید؛ فونت وزیرمتن داخل خود فایل جاسازی شده و به اینترنت نیاز ندارد.

سه طرح قابل انتخاب دارد: Studio بنفش، Focus فیروزه‌ای، Paper گرافیت/کاغذ. هر سه تم روشن/تیره، انتخاب روش جمع‌آوری، سوییچ جستجوی عمیق، ردیف آیکون با tooltip و نمونهٔ تأیید ابزار دارند. متن زیر عنوان HASAYA حذف شده است.

این فایل صرفاً پیشنهاد طراحی است: دامنهٔ نمونه ساختگی است، هیچ اتصال به Chrome API، OCR، ترجمه، دریافت تصویر یا دانلود ندارد. تنظیمات پیشرفته جای‌نگهدار نمایشی است. هیچ فایل اجرایی افزونه تغییر نکرده و نسخهٔ واقعی 3.12 باقی است. انتقال به کد اصلی منوط به تأیید کاربر است؛ این فایل برای نصب به‌عنوان افزونه نیست.

بررسی انجام‌شده با Chromium واقعی: سه طرح × دو تم، نمایش تأیید و لغو با Escape، نبود متن حذف‌شده، نبود سرریز افقی در دسکتاپ و عرض ۳۹۰، و نبود درخواست منابع خارجی. تست کامل برنامه اجرا نشده چون کد اجرایی تغییر نکرده است.
